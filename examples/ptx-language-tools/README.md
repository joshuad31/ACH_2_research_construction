# PTX language-tool fragments

These are the latest surviving cumulative fragments from the PTX dictionary and canonicalizer experiments:

- [Mr. Dictionary fragment, pass 8](mr-dictionary-fragment.md)
- [Canonicalizer fragment, pass 2](canonicalizer-fragment.md)

Both files are exact copies of the saved fragments. They are experimental language-tool outputs. Their presence does not mean that the compact [illustrative PTX databases](../ptx-urination-illustrative/README.md) were produced by running these tools, or that every quoted source passage in the fragments has been independently rechecked for this publication.

The dictionary fragment carries earlier passes inside its cumulative record. The canonicalizer names a separate compiled dictionary view, which is outside this two-fragment selection. These files are separate from the compact FRD and witness database size comparisons.
